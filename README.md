# 🍵 Tea Flavor Aggregator

Приложение для агрегации и визуализации вкусо-ароматических дескрипторов чая из множества интернет-источников.

## Возможности

- **Поиск по сорту чая** — введите любое название (рус/eng), приложение соберёт отзывы и описания
- **6 источников данных**: Reddit r/tea, Steepster, RateTea, TeaVivre, Yunnan Sourcing, Web Search (DuckDuckGo)
- **Таксономия** — 9 главных категорий, 40+ подкатегорий, 200+ ключевых слов (рус + eng)
- **Дашборды:**
  - 🌸 Flavor Wheel (Sunburst-диаграмма)
  - 🕸️ Радарная диаграмма + Пирог
  - 📊 Горизонтальные bar-charts (категории, подкатегории, топ-дескрипторы)
  - 📈 Диаграмма Парето
  - 🗂️ Treemap
  - 🌡️ Тепловая карта по источникам
  - 📡 Stacked bar по источникам
  - ☁️ Облако слов
  - 🗃️ Таблицы с экспортом в CSV

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
streamlit run app.py
```

Откройте браузер: http://localhost:8501

## Использование

1. Введите название сорта чая в боковой панели (например, `Дянь Хун Мао Фэн` или `Dian Hong Mao Feng`)
2. Выберите источники данных
3. Нажмите **«Искать и анализировать»**
4. Или нажмите **«Загрузить демо-данные»** для быстрого старта без ожидания

## Структура проекта

```
app.py          — Streamlit-дашборд (главный файл)
scrapers.py     — Скраперы для каждого источника
aggregator.py   — Извлечение и агрегация дескрипторов
taxonomy.py     — Вкусо-ароматическое колесо (таксономия)
requirements.txt
```
